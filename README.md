# The Odin Project / Ruby Course: Chess

This is the capstone project for the Ruby Course in The Odin Project. It is a chess game,
to be played in the terminal. Note that the display may not work properly when using 
Terminal in MacOS. For testing in the MacOS environment, [iTerm2](https://iterm2.com/) 
is recommended. Thanks to Josh Smith for this helpful 
[article](https://dev.to/joshdevhub/terminal-colors-using-ruby-410p) on using colors in 
the terminal.

Work in progress

Update 8 April 2026: The game is working now. Some methods are still too long and most 
classes surpass Sandi Metz's suggestion of 100 lines or less, and more refactoring is
certainly necessary, but I am happy with functionality (until I discover the *next* 
bug...). Saving, Loading saved games and loading from FEN are all possible. Typing
'fen' (case insensitive) during gameplay will output the current FEN code. I have 
two other color schemes that I might work into the opening as well, so the player can
select the board color. Other features I might add are player names, and a simple AI.
But for now, I'm pretty happy with myself. This is by far the biggest project I've
ever coded, and somehow, it came out better than I thought it would. It was a challenge
to be sure, but I enjoyed the entire process. Really getting into this coding thing :).
